## 1. 环境与命令

- 后端：`mvn -B spring-boot:run`，H2 文件库 `./data/e2e-verify`，`SERVER_PORT=8081`、`RATE_LIMIT_ENABLED=false`
  （e2e 需要关闭 auth 限流，否则 globalSetup 单次登录后的 `/api/auth/me` 会叠加成 429）。
- 前端：`npm run build` → `vite preview`（4173，`/api` 反代到 8081，`E2E_API_TARGET=http://localhost:8081`）。
- 命令：

```bash
cd travel-agent-web
E2E_API_TARGET=http://localhost:8081 npx playwright test --reporter=list
```

（`aria-label="更多行程操作"`）二级菜单。**是断言过期，不是功能回归**；修正后 8/8。

- `e2e/smoke.spec.ts`：改为点开「更多行程操作」，断言 `menuitem`「导出路书 PDF」可见。
- `e2e/planner-form.spec.ts`：确认后跳转行程页，同样按二级菜单断言。
