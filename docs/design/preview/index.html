设计说明（评审要点）

这一版的判断标准只有一句话：能不能每天打开用。所以去掉了装饰性材质，把预算、待办、行程状态这些「每天要看一眼」的信息提到首屏。

相对现状的改动

  • 移除极光背景、backdrop-filter 毛玻璃与高光描边
  • 圆角从 16–24px 收敛到 6–14px，阴影从多层降到两层极浅阴影
  • 新增 KPI 状态条（待办 / 日程 / 支出 / 足迹），首页不再只有入口
  • 行程页把「预算 / 已花」提升为常驻状态，Diff 确认留在对话流里
  • 补移动端：底部标签栏 + 单列卡片 + 常驻输入条
  • 补暗色主题（现状只有足迹地图内部有 dark）

设计令牌

  • 表面：--bg / --surface / --surface-2 / --border
  • 文字：--text / --text-2 / --text-3
  • 强调：--accent（一组即可，语义色 --ok/--warn/--danger）
  • 圆角：--r-sm 6 / --r-md 10 / --r-lg 14
  • 间距：4 / 8 / 12 / 16 / 20 / 24 / 32
  • 字号：11 / 12 / 13 / 14 / 16 / 20 / 24
accent ok warn danger surface bg

响应式规则

  • ≥ 1080px：左侧栏 232px，内容区最大 1180px，首页两栏（主列 + 右栏）
  • 720–1080px：侧栏收成 72px 图标栏，首页右栏下沉为第二行
  • < 720px：底部标签栏 4 项，卡片单列贴边，主要操作为常驻输入条
  • 行程页在窄屏按「地图 → 时间轴 → 助手」顺序堆叠，助手可全屏

落地顺序建议

  • 第一步：替换 global.css 的 :root 令牌与外壳（AppShell）
  • 第二步：首页、行程页两屏按本稿重排（占日常使用绝大多数时间）
  • 第三步：其余 13 页只做「换令牌 + 去装饰 + 补窄屏」，不改信息架构
  • 第四步：antd 主题 token 同步成同一套色值，避免两套视觉并存
