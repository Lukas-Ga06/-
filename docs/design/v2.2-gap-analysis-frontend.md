### A.4 SSE 消费链路（事件类型 → UI 的映射）

**通道**（`src/api/agent.ts`）：
- `streamAgentChat`（GET）：`EventSource('/api/agent/stream?...&ticket=...')`，消息走 URL（≤500 字），票据为 `agent-stream` 用途短期只读票；`es.onerror` → 「与 Agent 的连接已中断，请重试」（修复过 streaming 卡死问题，见 L85–92 注释）。
- `streamAgentChatPost`（POST）：`fetch` + `credentials:'same-origin'` + `ReadableStream` 手工解析 `event:`/`data:` 帧，`\n\n` 分块；结构化规划表单（攻略正文可达 1.8 万字）专用。Planner 提交即走此通道（`SendPayload.transport='post'`）。

**事件类型 → UI 映射**（`agentStore.send` 的 `onEvent` + `STAGE_TEXT` 表，L62–74）：

| SSE 事件 | STAGE_TEXT 映射 | UI 落点 |
|---|---|---|
| `start` | 「已连接 Agent…」 | `ChatPanel` 的 `.chat-stage` 单行 + 三点动画（`src/components/ChatPanel/index.tsx` L68–77） |
| `intent` | 「意图识别：{intent}」 | 同上 |
| `planning` | 「正在规划行程…」 | 同上 |
| `tool_call` | `search_city_online` 专属文案「联网查询目的地的景点/酒店/餐厅数据…」，否则「调用工具 {tool}…」 | 同上（**仅单行文本，无参数展示**） |
| `tool_result` | 「工具 {tool} 执行完成」 | 同上 |
| `rag_result` | 「检索旅游知识库…」 | 同上 |
| `plan_update` | 「生成方案对比…」 | 同上 |
| `confirmation` | 「等待你的确认…」 | 同上（注意：`pendingConfirm` 实际在 `complete` 才挂起） |
| `focus` | （无文案） | `set({ lastFocus: data })` → Trip 页 `useEffect` 同步 `setSelectedDay(focus.day)`（`src/pages/Trip/index.tsx` L67–69）+ `MapView` `flyTo` 定位（L48–66）+ `Timeline` 自动滚动到 `ti-{itemId}`（`src/components/Timeline/index.tsx` L35–42） |
| `complete` | —（终止流） | `AgentResult` → 追加助手消息；`status==='NEED_CONFIRMATION'` → `pendingConfirm` → `PlanDiff` Modal；`COMPLETED && tripId && !payload.tripId` → `committedTripId` → Planner 页跳 `/trip/:id` |
| `error` | —（不终止，等服务端补发 complete） | `onError` → 追加「⚠ …」助手消息、`streaming=false` |

**补充**：`confirmPlan/cancelPlan/undoTrip/getPendingPlan/clearConversation` 均为普通 REST（`/agent/confirm` 等）。`getPendingPlan` 用于 Assistant 页刷新后凭 URL `planId` 恢复确认弹窗（`src/pages/Assistant/index.tsx` L44–59）。

### A.5 地图实现方式

**① 行程地图（Trip 页）— 高德 JS API 2.0，Provider 抽象**
- `src/components/MapView/MapProvider.ts`：`MapProvider` 接口（`init/render/flyTo/destroy` + 可选 `startTour/stopTour/setPitched`），**坐标契约：入参一律 WGS-84**，实现内部转 GCJ-02。
- `src/components/MapView/AMapProvider.ts`：唯一实现。`render(items, focusDay)`：按 `dayIndex` 分桶配色（`DAY_COLORS` 5 色循环），每天两层 Polyline（辉光层 strokeOpacity 0.14/0.3 + 实线层），`focusDay` 当日加粗加亮；每个 item 一个 DOM Marker；`JSON.stringify` 渲染 key 去重（id 不变但坐标/标题/时间变了也重绘，L125–139）；`didInitialFit` 首次 `setFitView`；底图 12s 超时 + error 回调上报 ok/failed。
- `src/components/MapView/markerElement.ts`：`createElement + textContent` 构建标记 DOM（**防 XSS，有单测**），类型图标 🏨📍🍽🚗。
- `src/components/MapView/amapLoader.ts`：SDK 单例懒加载（script id 去重、15s 超时、HMR 清理、缺 Key 明确报错文案）。
- `src/lib/coords.ts`：WGS-84 ↔ GCJ-02（境外不偏移，有单测）。
- `src/components/MapView/index.tsx`：3D/2D 引擎切换（重建 provider）、沿路线巡航（3 秒/站，按 startTime 排序）、`focus` 飞行定位（`flyTo` zoom16 + pitch65）、`focusDay` 切换停巡航、`mapLoadFailed` 时 `.map-tile-hint` 降级提示（提示 VITE_AMAP_KEY 等）。
- 数据来源：`tripStore.items`（`ItineraryItem`，`types/trip.ts`：`dayIndex/itemType/startTime/lat/lng/cost/tags`）。

**② 足迹地图（Home 缩略 + Footprint 页全屏）— MapLibre GL，globe 投影**
- `src/components/FootprintMap/index.tsx`：`maplibregl.Map` + `projection:'globe'`（特性探测）；底图三选一 + 降级链（高德栅格 → OSM 栅格 → 暗色 OpenFreeMap 矢量 → 压暗 OSM 栅格）；`fp-route` GeoJSON source + glow/core/dash 三层线；DOM marker（`textContext` 安全写入）+ `setDOMContent` Popup；模式 `trip`（每行程一节点）/`city`（按城市聚合，节点显示 ×N 到访次数）；回放 tour（3 秒/站）、autoSpin 环绕、`focusTripId` 飞入、`playSignal` 触发回放；用户交互（drag/rotate/zoom start）自动停环绕。
- `src/components/FootprintMap/footprintData.ts`：纯函数（排序、连线坐标、统计、城市聚合、年份过滤），全部有单测。
- `src/components/FootprintMap/basemap.ts`：底图样式构建（有单测）。

### A.6 其余关键链路

- **指代消解上下文**：`ChatPanel.doSend` 携带 `tripId + currentDay(uiStore.selectedDay) + selectedElement`（`src/components/ChatPanel/index.tsx` L36–41）；`selectedElement` 由 `Timeline` 点击 `ItineraryCard` 设置（Chip 显示在输入框上方可关闭）。后端凭 `conversationId` 回放历史。
- **预算口径**：`getBudgetExecution`（计划/预算/实际/偏差/执行率/分类/按天）+ 前端兜底（`ExpensePanel` 拿不到时用当前页 `summarize`）。
- **分页契约**：`getPage` + `keepEnvelope` + `readPagination`，`pagination===null` 时按单页降级（`PaginationBar` 组件统一翻页 UI）。
- **提醒**：`ReminderBell` + `reminderNotify`（后台 Notification，会话内去重）。
- **离线**：`OfflineBanner` + `useOnlineStatus`（挂载时校准）。

## D. 不可破坏的现有行为（回归红线清单）

1. **确认弹窗链路（Human-in-the-loop）**：`agentStore.pendingConfirm` → `PlanDiff` Modal → 确认/取消。e2e 依赖 `data-testid="plan-diff-dialog"`（内容容器上，非 Modal 根，见 `PlanDiff/index.tsx` L49–50 注释——零尺寸元素 Playwright 判 hidden）与 `okButtonProps` 透传的 `data-testid="plan-diff-confirm"`。`highRisk` → danger 按钮 + 超预算警示文案必须保留。
2. **撤销（undo）**：Trip 页「撤销上一次 AI 修改」按钮 → `undoTrip(tripId)` → 重新 `loadItinerary`（`src/pages/Trip/index.tsx` L83–94）。
3. **指代消解（多模态上下文）**：`conversationId` sessionStorage 持久化（跨页面切换同一对话，`reset()` 不动它）；`ChatPanel` 发送携带 `currentDay + selectedElement`；时间线点选卡片 → `uiStore.selectedElement` chip → 可关闭。V2.2 改 run 化时必须保留这套上下文注入。
4. **暗色模式**：三件套契约 —— `index.html` 首帧内联脚本（`travel-agent-theme` key，与 themeStore merge 规则一致）+ `themeStore.applyTheme` 写 `<html data-theme>` + `global.css` `[data-theme='dark']` 令牌层 + `main.tsx` antd darkAlgorithm。⚠️ 已知不一致：`BudgetChart`/`ExpensePanel` 内 ECharts 文本色是硬编码浅色值（`TEXT='rgba(28,28,30,0.9)'`），暗色抽屉下图表文字偏暗——改造预算面板时可顺手接入主题令牌，但**不能在无回归验证下大改**。
5. **移动端 390px**：`global.css` `@media (max-width:720px)`（L3035–3114）：侧栏隐藏 + 底部标签栏（`app-tabbar`，`env(safe-area-inset-bottom)`）、antd Drawer `max-width:100vw`、Modal wrap 夹宽、长标题 `overflow-wrap:anywhere`、`.ant-table-wrapper` 内部横滚、`.plan-footer/.page-actions` 换行。`index.html` `viewport-fit=cover`。
6. **PWA**：只预缓存 app shell；三条只读 GET NetworkFirst（`itinerary-v1`，5min/50 条、只缓存 200）；`/api` 整前缀不做导航回退（**SSE 绝不能进缓存**）；`cleanupOutdatedCaches`。改缓存策略需 bump `ITINERARY_CACHE_NAME` 版本号。
7. **SSE 鉴权与双通道**：GET 走 `agent-stream` 短期票据（不落 JWT 进 URL/日志）；POST 走 Cookie + 请求体（长文本）；票据按用途分桶缓存（照片 `media-read` 不得挪用）；`error` 事件后服务端还会补 `complete`，前端不能提前终止流；连接层 onerror 必须终结 streaming（历史 bug 修复，勿回退）。
8. **登录态恢复语义（B8）**：401=登出；429/5xx=保留登录态 + 1s/2s 退避重试 + `SessionRecoveryFailed` 兜底页；登录/注册/me 接口 401 不触发跳转；已在 `/login` 不跳（防循环刷新）。e2e 依赖 `data-testid="session-recovery-failed"`。
9. **行程三态操作**：Travel 页一个按钮承载 确认/取消/恢复（`PLANNING→CONFIRMED / CONFIRMED→CANCELLED / CANCELLED→CONFIRMED`，PAST 无操作）+ Popconfirm 删除 + `statusBusy` 防并发。
10. **会话记忆生命周期**：`newConversation` 生成新 ID 并调 `/agent/conversation/clear` 清服务端历史（失败静默，7 天定期清理兜底）；Assistant 页离开时非 `?q=` 场景 `reset()`；Planner 进/离均 `reset()`。
11. **路由兼容重定向**：`/schedule → /travel?tab=schedule`、`/footprint → /travel?tab=footprint`（旧链接必须继续可用）；`*` → `/`。
12. **XSS 防线**：地图标记/弹窗一律 `createElement + textContent` / `setDOMContent`，禁止 `innerHTML`/`setHTML`（用户输入与 LLM 输出会进地图）。
13. **e2e data-testid 契约**：`app-shell-brand`、`planner-destination`、`planner-submit`、`plan-diff-dialog`、`plan-diff-confirm`、`theme-toggle-sidebar`、`theme-toggle-tabbar`、`session-recovery-failed`。改造时不得移除。
14. **分页降级**：`pagination===null` → 单页、无更多（不许报错或空白）；ExpensePanel 删最后一条回退一页。
15. **离线提示**：`OfflineBanner` 全路由外层挂载（登录页/规划页不套 AppShell 也能看到）。
16. **语音输入**：`VoiceButton`（Web Speech API，不支持的浏览器自动隐藏——返回 null）。
17. **路书导出**：`window.open('/api/trips/{id}/guidebook.pdf')` 同源 Cookie 顶层导航。
18. **性能既有约定**：路由 lazy + manualChunks（echarts/maps/antd）+ `optimizeDeps.exclude: ['maplibre-gl']`；首页 FootprintMap 懒加载。新增大依赖须维持分包。
19. **可访问性既有做法**：Footprint 列表行 `role="button" tabIndex={0}` + Enter/Space 键控；地图 marker `aria-label`；主题按钮 `aria-label`。新增交互应延续。
